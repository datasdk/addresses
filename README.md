# Addresses

Address and Contact models and traits for MyProject.

## Installation

```bash
composer require datasdk/addresses
```

## Autoload

```json
{
    "autoload": {
        "psr-4": {
            "MyProject\\Addresses\\": "src/"
        }
    }
}
```

## Namespace

- Models: `MyProject\Addresses\Models\Address`, `MyProject\Addresses\Models\Contact`
- Traits: `MyProject\Addresses\Traits\HasAddresses`, `MyProject\Addresses\Traits\HasContacts`
